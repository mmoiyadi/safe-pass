# Project 1: Build a Password Manager

## Goal

Build a personal password manager that supports secure storage, sharing, and custom data templates. The objective is to design and implement a complete application (frontend, backend, database, and PWA) using AI-assisted development.

## Functional Requirements

### Authentication

* Login using a master password.
* Secure session management.

### Vaults

* Personal vault.
* Create multiple vaults.
* Vaults can be:

  * Private
  * Shared with other users (e.g., family members).

### Secrets

Store different types of information, for example:

* Website accounts
* Credit cards
* PAN cards
* Secure notes
* Any custom data

### Encryption

* All secret data must be encrypted with user password

### Templates

* Built-in templates for common secret types.
* Create new custom templates.
* Add custom fields to existing templates.

### Search & Organisation

* Search secrets.
* Organise using folders or tags.

### 2FA

* Google authenticator or similar app for second factor authentication.

## Technical Requirements

* Web application
* Backend API
* Database
* Progressive Web App (PWA) with mobile-friendly UI

## Suggested Enhancements (Optional)

* Password generator
* Password strength indicator
* Copy to clipboard
* Auto-lock after inactivity
* Dark mode
* Import/export data
* Google Drive integration for backup/restore.
* Audit log for shared vaults

## Instructions

Don't try to implement everything upfront. Build incrementally and let AI help you make design decisions. Ask relevant questions before implementing each feature (e.g., data model, security, sharing permissions, UI behaviour) instead of making assumptions. Focus on understanding the problem, breaking it into smaller tasks, and iterating.
